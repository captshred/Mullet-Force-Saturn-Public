## Bat direction, including the user's correction

The initial forward-up/down candidate sequence was rejected before gameplay integration. The user clarified that the strike must start behind and rotate **counterclockwise into full extension**, then **continue counterclockwise upward after impact**. The final right-facing screen-space grip-to-tip directions decrease monotonically: approximately **-127°, -183°, -223°, -334°, -365°, -415°**. With screen Y pointing down this is physically counterclockwise; hardware mirroring reverses it correctly for left-facing attacks. Native pixel observations, rather than filenames, are recorded in `assets/attack-sequence/arc-observations.json`. Bat lengths measured from native grip/tip markers are approximately35–37 pixels. Diagnostic red/cyan marks are preview-only.

Counters1–2: exact last visible running upper/carry pose (standing attack uses carry0), feet already planted. Counters3–4: rear-left barrel. Counters5–6: rear-down barrel. Counters7–11: forward/down acceleration. Counters12–17: original horizontal impact. Counters18–36: upward counterclockwise follow-through held during existing recovery. At completion the original guard/walk resumes. There is no old raised standing windup, no backward/up reset before impact, and no running-leg cycling. Standing and running share strike/follow-through art; standing preparation is the brief planted carry entry.

Four clipped original running uppers per fighter preserve each possible last visible carry pose exactly; one per-player presentation cache records only the last *drawn* dash phase. The bank never advances that phase during a strike. The carried bat is the existing shared RBV resource. Two extra shared native rotations handle the rear sweep around the same rear-hand grip. Original jab/impact upper pixels are reused. Only two arm/weapon guide poses per fighter are converted: forward/down acceleration and upward follow-through. They are registered at the same waist, restored with original opaque face/hair pixels, binary-alpha indexed to the existing palette and hand-connected. The new follow-through barrel alone is shortened to the approved carry length; no head/body scaling. Clean lower strips remain fixed throughout every attack key. Upper weapon strips use the existing front-depth convention when overlapping thighs.

The animation is deliberately discrete, not a full hand-drawn inbetween sequence: the fast lower sweep skips some intermediate angles, and the up-follow pose is held for the unchanged recovery. Bat removal at the original attack end still follows existing gameplay; no persistent weapon/equip state or additional recovery drawing is introduced. Native before/after and full run→strike GIFs expose these limits rather than substituting isolated poses for a transition preview.
