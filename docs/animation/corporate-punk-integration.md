No AI population increase is included.

## Completed local verification

The controller-driven local Yabause HLE/software test ran **2800 frames per build**, comparing this renderer against the published knee-lift parent build. **2470 gameplay frames had byte-identical simulation state**. It compared **375840 unoccluded native enemy pixels with zero mismatches**, covering all three walking poses and both facings, and observed all eight existing enemy states during two-player gameplay. VDP1 texture bytes remained unchanged throughout gameplay. Native sprite seam/mirror checks and warm-palette conversion checks are also part of independent export validation. Idle timing/independent actor clocks/fallback selection are unit tested; the controller run did not expose enough unobstructed idle artwork to pixel-validate all three idle poses. Visual idle approval remains a playtest item.

Read-only runtime memory inspection measured **365120 texture bytes and134 slots**. A separate1600-frame controller test entered the old comparison gallery, measured **441120 bytes /185 slots**, compared28800 preview pixels with zero differences, returned to gameplay and verified no further texture changes. Screenshots in `corporate-punk-captures` are genuine emulator captures from this local implementation, not composites. The sidecar JSON reports identify the core and method. No physical Saturn or WebRetro runtime claim is made.

Native build, `make check`, `make test`, and Corporate Punk export validation passed locally. Existing player sources, Timing B header, game.c/game.h, shipped legacy enemy/other assets and original approved master are unchanged. CI separately builds the integration flag and all prior configurations. Local runtime tests require the already-built core (SHA256 recorded in reports); they are not automatically installed or run by CI.

Remaining review points: native84px facial detail, the aggressive21-tick three-step cadence, subtle idle readability, and the documented visual style/height change into legacy attacks/hurt/death. No new fallback artwork was invented to conceal that limitation. Hardware fill rate/frame pacing and browser WebRetro compatibility still require user testing. CPU-side cost is two small presentation clocks and at most four extra sprite submissions for the existing two-enemy population; no measured Saturn CPU/FPS claim is made.
